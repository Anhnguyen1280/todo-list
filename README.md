# My Todo List

A responsive Todo List application built with HTML, CSS, and JavaScript.

The application helps users create, organize, search, filter, and manage daily tasks. Data and theme preferences are saved in the browser using localStorage.

## Features

- Add new tasks
- Edit task name, due date, and priority
- Delete tasks with a confirmation modal
- Mark individual tasks as completed
- Complete or uncomplete all tasks
- Clear completed tasks
- Search tasks by name
- Filter by All, Active, and Completed
- Sort by priority or due date
- Display overdue tasks
- Track completion progress
- Light and Dark Mode
- Toast notifications
- Empty-state messages
- Responsive design for desktop, tablet, and mobile
- Keyboard-accessible Edit and Delete modals
- Save tasks and theme using localStorage

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
